R87 APPAREL MOCKUP GALLERY
==========================

HOW TO RUN
1. Extract the ZIP file.
2. Open the r87_apparel_website folder.
3. Double-click index.html, or open the folder in VS Code and use Live Server.

FILES
- index.html: page structure
- style.css: layout, colors and responsive design
- script.js: category filters, search, sorting and product preview modal
- images/: starter image crops from your supplied reference screenshot

IMPORTANT CUSTOMIZATION
- Replace the starter images in the images folder with your own high-quality mockups.
- In index.html, replace https://www.facebook.com/ with your real Facebook Page URL.
- In script.js, replace 000000000000000 with your Facebook Page's Messenger username or page ID.
- Edit the products array in script.js to add, remove or rename mockups and categories.
- Prices are intentionally shown as INQUIRE FOR PRICE so you can set your own rates.

This is a front-end demo only: HTML, CSS and JavaScript. It does not save orders to a database.
